# skillgrade

Purpose-built skill-eval framework (the sharpest external cross-check of koan's benchmark design).

**Candidate (net-new — triage)**
- **Normalized Gain as the delta gate, quantified.** `NG = (p_with − p_without)/(1 − p_without)` is koan's D-013 delta gate expressed as a *continuous* metric weighted by headroom: a rule lifting an already-strong baseline (small `1 − p_without`) must produce a larger raw gain to score the same NG as one with lots of room. It also encodes D-013's cut heuristic exactly — `p_without = 1` (baseline already passes) ⇒ `NG = 0` (or `−1` if the skill breaks it), i.e. the rule earns nothing. koan reads its probes as a **binary** flip/no-flip (D-013) at **small n** (n=1 sampling, 2-of-3 at promotion — D-022); NG's precision only materializes at the 15–30-trial pass rates skillgrade runs, which koan bounds away by design. · skillgrade src/analytics/engine.ts + README · _log-only 2026-07-11 (human triage — NG is the formal statement of what D-013 already gates; a benchmarks/README note would reference a metric koan deliberately doesn't compute at its trial budget, a no-op by koan's own no-op test). Revisit if koan ever raises trial counts (reopens D-022), which would make NG computable and the note load-bearing._
