# ingest/sources

Drop reference repos here to distill (see `../distill.md`). Contents are
gitignored — clone or symlink, don't commit other people's repos.

```
git clone <repo-url> ingest/sources/<name>
```

Seeded lessons in `../lessons/` came from `ponytail` and the `handoff-*` skills (see `../LESSONS.md` for the index).
